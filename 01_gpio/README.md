# 01 - GPIO Register-Level Programming

## Objective

Configure a GPIO pin of the STM32F4 microcontroller
using direct register access.

## Concepts

- RCC GPIO clock enable
- GPIO MODER register
- GPIO output configuration
- GPIO ODR / BSRR register
- Register-level programming

## Hardware

- STM32F4 Nucleo board
- On-board LED

## Programming Approach

This experiment avoids HAL functions and directly accesses
the STM32 peripheral registers.
